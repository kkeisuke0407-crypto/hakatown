## 有望そうな枝（SERPからの見立て。KWPで要確認）

- **公営霊園の落選**：「公営霊園 抽選 落ちた」の上位8件が「落選後に検討できる納骨先」。
  「都立霊園に落選した約7割が民営霊園を購入」という記事あり → 落選・倍率の語は購入直前の層
- **屋内墓苑・室内墓所・室内霊園**：上位が地域別の霊園一覧。納骨堂の言い換えで、競合が拾いにくい
- **樹木葬の型**：個別型／集合型／合祀型、合祀なし、満期・期限 → 契約条件を比べている層
- **墓を新しく持つ立場**：次男・分家・嫁いだ娘・「夫の墓に入りたくない」（関連検索に出た）
- **空き区画・募集区画・新区画**：霊園の空き区画案内・募集が上位
- **費用の業界語**：建墓費用・墓地使用料・永代使用権・墓石セット・メモリアルローン・相見積もり
- **生前購入の動機**：祭祀財産（お墓は相続税がかからない）・生前墓の税金
- 関連する質問で何度も出た問い：「一番お金がかからないお墓はどれですか？」「維持費がかからないお墓はありますか？」

## 死んだ枝（SERPで遠いと判断）

- 寿陵：意味・縁起の解説が中心。関連検索に無関係の四字熟語「寿陵余子」
- 納骨堂 何柱：「柱」の数え方の解説
- お墓 年間管理費 相場：関連が「滞納」「封筒」「誰が払う」＝既にお墓を持っている人
- 墓じまい 不要 お墓：上位が「墓じまいしないとどうなる」＝既存墓の放置。お墓選びの条件としては使われていない（除外）

## 要判断（案件の規制ルール `rules_ohaka.py` との関係）

- 「ペット」は案件ルールで**別市場（HIGH）**。ただし「ペットと一緒に入れるお墓」のSERPは人の霊園一覧で、墓探しの意図
- 「仏壇型 納骨堂」「位牌式 納骨堂」は「仏壇」「位牌」でHIGHになるが、納骨堂の型の名前
- 「公営」「抽選」はMEDIUM（自治体窓口・公営申込）。ただし落選後の語は民営を探す意図
- いずれもルールファイルは変えず、⑨で「保留（案件ルールと要判断）」に分ける
