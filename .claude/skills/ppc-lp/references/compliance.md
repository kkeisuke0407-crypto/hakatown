## 1. 文体

- **やさしい日本語。** 1文は短く、修飾を重ねない
- 話し言葉に寄せる（「これ、自分でやると結構大変です。」）
- 専門語は使った直後に言い換える
- **読者を責めない。**「調べ方が悪い」ではなく「調べる作業が大変」

### 断定を避ける

広告基準の話であると同時に、信頼の問題。
言い切られると、読者は「本当かな」と身構える。

| 使わない | 使う |
| --- | --- |
| いちばん選ばれています | 今回の調査では最も多く選ばれています |
| いちばん抑えられます | 抑えやすい傾向があります |
| 〜が要らなくなります | 〜の手間を減らせます |
| 〜のほうが早い | 〜のほうが考えやすくなります |

**根拠のない「No.1」「最大級」は追加しない。**

## 2. 章から章へのつなぎ

各章の終わりに1行だけ「渡し」を置く（`.bridge`）。

- 中央寄せ、本文より小さいグレー、下に ↓
- **次の章の問いを先に出す**（「とはいえ、どこが運営しているのか。」）
- CTA直後にも置く。クリックしない人がそのまま読み進められる

渡しがないと、スクロール中に「ここで終わったのかな」と離脱する。

## 3. 必ず入れる

| 項目 | 場所 |
| --- | --- |
| PR表記 | FV直下 |
| ※本記事中の画像はイメージです。 | FV右上 |
| ※本記事の金額・内容は一例です。 | FV右上 |
| ※本記事ではAI生成画像を使用しています。 | フッター |
| 運営者名＋運営者情報ページ | フッター |
| 数値の出典＋確認日 | その数値のすぐ近く |

運営者情報ページには、**事実でない所在地・連絡先を書かない。**
書けるものだけ書く（サイト名・運営者名・運営開始日など）。

## 4. 入れない

- **申込可能な社数**（「1社でも構いません」等）
- **金額レンジを前面に出す**（FV・H1に「5万〜150万円」等）。
  本文のタイプ説明の中に置くのは可
- 根拠のない最上級表現
- 広告主が禁止する領域（補助金・助成金など案件ごとに確認）

## 5. 数値の扱い

- 出典・調査時点・母数・「全国平均ではない」旨を必ず添える
- 金額を出す場合は「エリアや種別が異なる場合も含まれる」旨を添える
- **数値を消したら、その出典注記も消す。** 対象を失った注記が残っていると
  読み手に意味が通らない。これも実際に起きた

## 6. 機械検査

**目視だけで確認しない。**
コピー・H1/H2・CSS・HTML構造・画像配置のどれかを触ったら、必ず機械検査を通す。

| スクリプト | 見るもの |
| --- | --- |
| `tools/verify_copy.py` | コピーの一致、共通部がマスターと同一か、計測タグの欠落 |
| `tools/qa_lp.mjs` | 横スクロール、はみ出し、FVの重なり、画像切れ、CTA数、演出の生存 |

検査幅：`320 / 360 / 375 / 390 / 414 / 820px`

```bash
python3 tools/build_lp.py      # 横展開を再生成
python3 tools/verify_copy.py   # → NG 0
node tools/qa_lp.mjs '["slug-a","slug-b", …]'   # → 検出された問題: なし
```

## 7. 過去に検査をすり抜けた失敗

**演出の「効いていること」を、結果だけで判定しない。**

スクロールイン演出の検査を「隠れている見出しの数」で見ていたため、
演出CSSごと消えたときに0件＝正常と判定してしまった。
いまは **CSSの存在そのもの**（`transition` が生きているか、
マーカーの色が想定値か）を確認している。

検査を書くときは、「壊れたらこの数字はどう動くか」を必ず一度考える。
壊れた状態と正常な状態が同じ値になる検査は、検査になっていない。

**CSSをまとめて削除するときは、削除範囲にほかのブロックが
挟まっていないか必ず確認する。** これで一度、サービス名の赤ハイライトと
全章の演出を巻き添えで消している。

## 8. 公開前チェックリスト

### A. 機械検査（必ず通す）

- [ ] `verify_copy.py` が NG 0 で完走した
- [ ] `qa_lp.mjs` が「検出された問題: なし」
- [ ] 320 / 360 / 375 / 390 / 414 / 820px すべてで通った
- [ ] 生成し直しても、コミット済みのHTMLと差分が出ない
      （= 生成器が最新。手編集が残っていない）

**色を触ったときだけ追加**

- [ ] コントラスト検査を通した（WCAG AA：通常4.5:1 / 大きい文字3:1）
- [ ] 線・面用の色（`--gold-line` `--accent`）を文字に使っていない

**画像を差し替えたときだけ追加**

- [ ] ファイルが途中で切れていない
      ```bash
      python3 -c "d=open('画像.webp','rb').read(); print(len(d), int.from_bytes(d[4:8],'little')+8)"
      ```
      **2つの数字が一致すること。** ズレていたら壊れたファイル
- [ ] `<img>` の `width` / `height` を実寸に合わせた（ズレるとCLS）
- [ ] 1枚1MBを超えていない（広告LPなのでWebP化する）

### B. 内容

**構成**

- [ ] FVの最初のH2で、検索意図に即答している
- [ ] 「痛み → 認識転換 → サービス登場」の順になっている
- [ ] 認識転換より前にサービス名を出していない
- [ ] 前置き・目次・SEO目的の長文がない
- [ ] 各章の終わりに渡しの1行がある

**文体**

- [ ] 1文が長くない。修飾を重ねていない
- [ ] 断定表現がない（いちばん / 必ず / 要らなくなる / 〜のほうが早い）
- [ ] 根拠のない最上級（No.1 / 最大級）がない
- [ ] 読者を責める書き方になっていない

**見出し**

- [ ] 大見出しは1行に収まるものは1行、収まらないものは自然に折り返している
      （不自然な強制改行・1文字残りがない）
- [ ] 見出しの上の小ラベルが入っている
- [ ] H1とH2、H2とH3が形で区別できる
- [ ] title と H1 が食い違っていない

### C. 法務・広告基準

**入っているか**

- [ ] PR表記（FV直下）
- [ ] ※本記事中の画像はイメージです。（FV）
- [ ] ※本記事の金額・内容は一例です。（FV）
- [ ] ※本記事ではAI生成画像を使用しています。（フッター）
- [ ] 運営者名 ＋ 運営者情報ページへのリンク（フッター）
- [ ] すべての数値に出典・調査時点・母数・「全国平均ではない」旨

**入っていないか**

- [ ] 申込可能な社数の具体的言及（「1社でも構いません」等）
      ```bash
      grep -rn '1社\|[0-9]社まで\|最大[0-9]*社\|[0-9]社以上' index.html */index.html
      ```
- [ ] FV・H1に金額レンジ
- [ ] 広告主が禁止する領域（案件ごとに確認）

**整合**

- [ ] 数値を消した章に、対象を失った出典注記が残っていない
- [ ] 運営者情報ページに、事実でない所在地・連絡先を書いていない

### D. 計測

- [ ] GA4のIDが正しい
- [ ] CTAの遷移先がすべて同じ正しいURL
- [ ] `data-cta` の値が設置位置ごとに違う（使い回していない）
- [ ] `rel="sponsored noopener"` `target="_blank"` が付いている
- [ ] CTAの本数が想定どおり（`qa_lp.mjs` が数える）

### E. 最後に目視

スマホ実機で通しでスクロールして確認する。

- [ ] FVで人物やロゴが切れていない
- [ ] スクロール中、章の切れ目が分かる
- [ ] 赤が出てくるのはサービス名の1か所だけ
- [ ] CTAの光沢が動いている
- [ ] 白文字・薄すぎる文字で読めない箇所がない
- [ ] CSSを更新したなら、生成対象外のページ（`about/` 等）の
      キャッシュバスターも上げた

## 9. よくやる事故

過去に実際に起きたもの。

| 事故 | 防ぎ方 |
| --- | --- |
| CSSをまとめて消したら、間に挟まっていた別ブロックまで巻き添えで消えた | 削除範囲の**始点と終点の間に何があるか**を必ず確認する |
| 画像を差し替えたら真っ白になった（ファイルが途中で切れていた） | 上記のサイズ照合を通す |
| 帯をやめたのに白文字指定が残り、見出しが白地に白になった | 色を触ったらコントラスト検査 |
| 演出CSSごと消えたのに、検査が「隠れた要素0件」で正常判定した | 結果ではなく**CSSの存在**を検査する |
| 横展開LPを手編集したら、次の生成で消えた | マスターと `lp_data.py` だけを編集する |
| 生成対象外のページだけ古いCSSのままだった | チェックリストEの最終項目 |
| `FIXED_MARK` だけ直してH3を直さず、生成も検査も止まった | H3と `FIXED_MARK` はセットで直す |
