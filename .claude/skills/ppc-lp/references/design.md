## 1. 色の役割

`:root` の変数で役割を固定する。案件が変われば値は変わるが、**役割の数と分け方は変えない。**

| 用途 | 変数 | 値（お墓LPの場合） |
| --- | --- | --- |
| ブランド緑（見出し・CTA） | `--gold` `--cta` | `#176b65` `#167063` |
| 濃い緑（山場・CTA下線） | `--cta-bottom` | `#0c4e46` |
| **赤（サービス名だけ）** | `--hot` `--hot-bg` | `#c9372c` `#ffd8d2` |
| 見出しマーカー | `--mk` | `#cbe6da` |
| 本文マーカー | `--marker` | `#fff3ad` |
| 注記 | `--note` | `#767676` |
| 矢印・記号 | `--arrow` | `#3a7a69` |
| 金額・特典の文字 | `--accent-txt` | `#946416` |

### 赤はサービス名の1か所だけ

ページ内で赤が出てくるのが1回きりだから、スクロール中にそこで目が止まる。
**他に赤を足すと全部死ぬ。** 強調したい箇所が増えたら、赤ではなく
黄マーカーか `<strong>` を使う。

### 線・面用の色を文字に使わない

`--gold-line` `--accent` のような薄い色を文字に使うと、白地で読めなくなる。
文字用に `--arrow` `--accent-txt` `--note` が**別に用意してある**ので、そちらを使う。

過去に `--gold-line` の矢印（1.96:1）、`--accent` の特典見出し（3.28:1）が
そのまま入っていて、機械検査で拾った。目視では「薄いな」くらいにしか見えない。

## 2. 見出しの階層

**形で区別する。サイズだけで区別しない。**
流し読みしているとき、人はサイズの差を認識しない。マーカーや下線という
「形」の違いだけが、スクロール中に階層として伝わる。

| 階層 | 見た目 |
| --- | --- |
| 大見出し（h2） | 緑マーカー ＋ **記事幅いっぱいの下線4px** ＋ 上に小ラベル |
| 山場の大見出し | 同上、下線を5pxの濃緑に |
| 補足の章（FAQ） | マーカーなし、下線2pxの細線 |
| **サービス名** | **赤マーカー ＋ 赤の下線4px**（中央寄せ） |
| 中見出し（h3） | 緑の小さな四角 ■ を頭に置く |

- **大見出しは1行に収まるなら1行。** 無理に固定改行せず自然に折り返す。
  変な1語・1文字残りになる場合は、CSSではなく**文言を短くして**直す
- 見出しの上の小ラベル（`sec-eyebrow`）は4〜11文字。章の役割を言う
- 下線は章の区切り線も兼ねるので、**罫線を別に引かない**

セクション番号は振らない。番号は「全部読む前提」の記事の作法で、
広告の着地点では読者に長さを意識させるだけ。

## 3. 強調

- 1セクションに「大声」は1回まで
- 黄マーカー（`em-green`）も**1セクション1回**
- `<strong>` は文末の結論句に寄せる
- 全文を太字にしない。**太字だらけは太字がないのと同じ**

## 4. 動き

| 対象 | 動き |
| --- | --- |
| 章頭 | 視界に入ったらラベル→見出し→下線の順にふわっと（1回だけ） |
| サービス名 | 同上、下線は中央から左右に伸びる |
| CTA | 光沢が0.9秒かけて通り過ぎ、2.7秒休む（無限ループ） |

- 動かすのは `transform` と `opacity` だけ。**レイアウトを動かさない**（CLSゼロ）
- 隠す指定は `<html class="js-reveal">` が付いたときだけ有効。
  このクラスは IntersectionObserver があり、かつ
  `prefers-reduced-motion: reduce` でない場合だけ head で付与する
- **JS無効でも内容が必ず見えること。** ここを外すと本文が消える

光沢を重ねるときは `z-index:-1` や `isolation:isolate` を使わない。
ボタンの背景の裏に回り込んで見えなくなる。

## 5. 注記

- 11.5px / `--note #767676`（白地でコントラスト比4.54:1）
- **これ以上薄くしない。** 読めない注記は表示している意味がない
- 本文2段落の間に挟まない。図のキャプションか、セクションの末尾に置く

注記は「読ませたくないが、載せる義務があるもの」ではない。
読み手が確認したくなったときに読める濃さを保つ。

## 6. 画像

- WebP化する（広告LPなので速度が直接効く）。1枚1MBを超えない
- `<img>` の `width` / `height` を**実寸に合わせる**。ズレるとCLSが出る
- 差し替えたら、ファイルが途中で切れていないか確認する

```bash
python3 -c "d=open('画像.webp','rb').read(); print(len(d), int.from_bytes(d[4:8],'little')+8)"
```

**2つの数字が一致すること。** ズレていたら壊れたファイル。
過去に、宣言52,666バイト／実体39,166バイトのWebPが入っていて、
ブラウザは700×737と報告するのに1ピクセルも描かない、という状態になった。

## 7. CSSを触ったあとの検査

- コントラスト検査を通す（WCAG AA：通常4.5:1 / 大きい文字3:1）
- 線・面用の色を文字に使っていないか確認する
- **CSSをまとめて削除するときは、削除範囲の始点と終点の間に
  別のブロックが挟まっていないか必ず確認する。**
  一度これで、サービス名の赤ハイライトと全章の演出を巻き添えで消している
- 生成対象外のページ（`about/` 等）のキャッシュバスターも上げる。
  生成器が触らないので、ここだけ古いCSSのまま残る
